# Contributing

This repository is maintained primarily as a portfolio edition of a shipped
application. Focused bug reports and pull requests are welcome.

Before opening a pull request:

1. Build with Xcode 26 or newer.
2. Run the `InnerWhisper` test scheme.
3. Keep business logic out of SwiftUI views.
4. Preserve VoiceOver labels, Dynamic Type layouts, and Reduce Motion support.
5. Do not add copyrighted quote collections, credentials, or production
   service endpoints.
